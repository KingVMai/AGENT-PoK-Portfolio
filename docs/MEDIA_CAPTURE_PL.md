# Agent PoK — instrukcja przygotowania portfolio

## Zrzuty ekranu (4 pliki)

- `01-dashboard.png` — panel główny rozszerzenia; bez danych osobowych.
- `02-workspace-activity.png` — Workspace Activity / statusy i diagnostyka na danych demonstracyjnych.
- `03-task-result.png` — jedna krótka interakcja ChatGPT -> Agent PoK -> wynik.
- `04-continuity.png` — Initialize / Resume oraz Auto Continue to New Chat.

KDE neon / Plasma: uruchom **Spectacle**, wybierz obszar lub okno, zapisz PNG. Utrzymuj tę samą szerokość i czytelny rozmiar tekstu. Najpierw zamaskuj informacje prywatne poza kadrem lub przygotuj w pełni syntetyczne demo.

## Wideo: 45–75 sekund

1. Otwórz osobny czat i testowy workspace (bez prawdziwych projektów).
2. Uruchom Spectacle i wybierz nagrywanie obszaru ekranu; w razie potrzeby użyj OBS Studio.
3. Pokaż po kolei: panel -> zadanie do PoK -> lokalne wykonanie -> wynik w rozmowie -> diagnostykę.
4. Zatrzymaj nagrywanie i odtwórz CAŁY materiał. Sprawdź każdą klatkę pod kątem sekretów, nazw użytkownika, prywatnych ścieżek, powiadomień i treści rozmów.
5. W razie potrzeby przytnij w Kdenlive. Zachowaj plik WebM lub MP4; preferuj obraz 1080p i brak mikrofonu.
6. Nie publikuj surowego nagrania; do repo dodawaj dopiero wersję zaakceptowaną do publicznego udostępnienia.

Jeśli przełączanie między popupem a ChatGPT zamyka popup, zrób osobne ujęcia panelu. Nie trzeba pokazywać ich równocześnie.

W repo `screenshots/` oraz `media/` są foldery na zatwierdzone materiały; na tym etapie pozostają puste.

## Mobilny dashboard (dodatkowy materiał)

Po potwierdzeniu działania na iPhonie wykonaj piąty zrzut `05-mobile-webapp.png` w Safari, korzystając z tego samego Wi-Fi. Ukryj pasek adresu z lokalnym IP, rzeczywiste dane projektów, logi i informacje osobiste. Opublikujemy materiał dopiero po weryfikacji prywatności.
